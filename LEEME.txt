PUBLICACIÓN GRATUITA
Puede publicarse en GitHub Pages o Cloudflare Pages. Para publicar en GitHub Pages:
1. Crear/iniciar sesión en GitHub.
2. Crear un repositorio público llamado ciberdinetec.github.io (si está disponible).
3. Subir el contenido de esta carpeta a la raíz del repositorio.
4. En Settings > Pages, seleccionar Deploy from a branch y la rama main / root.
5. Esperar la publicación y probar la dirección generada.
